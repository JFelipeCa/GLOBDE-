# ⚠️ Restricciones del Proyecto — Globde

[⬅ Volver al README principal](../../README.md)

Restricciones definidas en la propuesta técnica inicial del proyecto:

- Requiere conexión a internet para funcionar.
- Solo usuarios registrados pueden agendar citas.
- La primera versión **no incluye pagos en línea**.
- Las notificaciones dependen del correo electrónico registrado por el usuario.
- La capacidad de almacenamiento depende del servidor donde se despliegue el sistema.
- El proyecto tiene fines **educativos** — desarrollado como ejercicio formativo del programa ADSO del SENA, no está auditado para un entorno de producción real.
