## Historia

**Como** cliente,
**quiero** ver el perfil de cada barbero con su nombre, especialidad y calificación promedio antes de agendar mi cita,
**para** tomar una decisión informada y elegir al profesional que mejor se adapte al servicio que deseo recibir.

---

## Criterios de aceptación

- **CA-1:** Dado que el cliente accede a la sección de reservas, entonces el sistema deberá mostrar la lista de barberos con su perfil y calificación.
- **CA-2:** Dado que un barbero no tenga calificaciones aún, entonces el sistema deberá mostrar 'Sin calificaciones aún'.
- **CA-3:** Dado que el cliente seleccione un barbero, entonces el sistema deberá mostrar su disponibilidad de horarios.
