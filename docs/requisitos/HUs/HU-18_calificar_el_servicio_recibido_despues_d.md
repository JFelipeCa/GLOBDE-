## Historia

**Como** cliente,
**quiero** calificar el servicio recibido después de que mi cita haya sido marcada como completada,
**para** compartir mi experiencia y ayudar a otros clientes a elegir el mejor barbero según las valoraciones del servicio.

---

## Criterios de aceptación

- **CA-1:** Dado que la cita esté marcada como completada, entonces el sistema deberá habilitar la opción de calificar el servicio.
- **CA-2:** Dado que el cliente envíe su calificación (1 a 5 estrellas y comentario opcional), entonces el sistema deberá registrarla y actualizarla en el perfil del barbero.
- **CA-3:** Dado que el cliente ya haya calificado esa cita, entonces el sistema no deberá permitir una segunda calificación.
