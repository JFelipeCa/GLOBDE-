## Historia

**Como** barbero,
**quiero** visualizar las citas programadas en la agenda del sistema organizadas por fecha y hora,
**para** poder planificar mi jornada laboral y tener un control claro de los clientes que serán atendidos durante el día.

---

## Criterios de aceptación

- **CA-1:** Dado que el barbero accede al módulo de agenda, entonces el sistema deberá mostrar las citas programadas por fecha y hora.
- **CA-2:** Dado que no hay citas registradas para una fecha, entonces el sistema deberá mostrar un mensaje indicando que no hay programaciones.
- **CA-3:** Dado que el barbero seleccione una cita, entonces el sistema deberá mostrar el detalle completo del cliente y el servicio.
