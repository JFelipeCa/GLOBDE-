## Historia

**Como** administrador,
**quiero** registrar los barberos del negocio con información como nombre, especialidad y datos de contacto,
**para** tener un directorio actualizado del personal disponible y asignarlos correctamente a las citas del sistema.

---

## Criterios de aceptación

- **CA-1:** Dado que el administrador ingresa todos los datos del barbero, entonces el sistema deberá guardar el registro y mostrarlo en el directorio.
- **CA-2:** Dado que el correo del barbero ya exista, entonces el sistema deberá mostrar un mensaje indicando que el barbero ya está registrado.
- **CA-3:** Dado que falten datos obligatorios, entonces el sistema deberá señalar los campos pendientes.
