## Historia

**Como** cliente,
**quiero** consultar mi saldo de puntos acumulados y el historial detallado de ganancias y canjes desde mi perfil,
**para** conocer cuántos puntos tengo disponibles y llevar un control de cómo los he obtenido o utilizado con el tiempo.

---

## Criterios de aceptación

- **CA-1:** Dado que el cliente accede a su perfil, entonces el sistema deberá mostrar el saldo actual de puntos de forma destacada.
- **CA-2:** Dado que el cliente acceda al historial, entonces el sistema deberá mostrar cada movimiento con fecha, concepto y cantidad de puntos.
- **CA-3:** Dado que no haya movimientos registrados, entonces el sistema deberá mostrar: 'Aún no tienes puntos acumulados'.
