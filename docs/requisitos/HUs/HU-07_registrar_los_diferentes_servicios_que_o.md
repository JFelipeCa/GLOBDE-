## Historia

**Como** administrador,
**quiero** registrar los diferentes servicios que ofrece la barbería incluyendo su nombre, precio y duración estimada,
**para** organizar de manera clara los servicios disponibles y facilitar la gestión de los datos dentro del sistema.

---

## Criterios de aceptación

- **CA-1:** Dado que el administrador ingresa todos los datos del servicio, entonces el sistema deberá guardar el registro.
- **CA-2:** Dado que falta información, entonces el sistema deberá mostrar un mensaje de error.
- **CA-3:** Dado que el servicio sea registrado correctamente, entonces deberá aparecer en la lista de servicios disponibles.
