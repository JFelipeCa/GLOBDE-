## Historia

**Como** cliente,
**quiero** seleccionar una fecha y un horario disponible para agendar mi cita en la barbería desde la plataforma web,
**para** reservar un turno en el momento que mejor se ajuste a mi disponibilidad sin necesidad de llamar o ir presencialmente.

---

## Criterios de aceptación

- **CA-1:** Dado que el cliente selecciona una fecha, entonces el sistema deberá mostrar los horarios disponibles para esa fecha.
- **CA-2:** Dado que el cliente elige un horario y confirma, entonces el sistema deberá registrar la cita y enviar confirmación.
- **CA-3:** Dado que el horario seleccionado ya esté ocupado, entonces el sistema deberá notificarlo e invitar a elegir otro.
