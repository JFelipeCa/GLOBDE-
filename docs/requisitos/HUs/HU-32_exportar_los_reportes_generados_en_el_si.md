---

## Historia

**Como** administrador,
**quiero** exportar los reportes generados en el sistema en formato Excel o PDF para compartirlos o archivarlos,
**para** presentar información del negocio a socios o propietarios y llevar un respaldo físico de los datos generados.

---

## Criterios de aceptación

- **CA-1:** Dado que el administrador genera un reporte, entonces el sistema deberá ofrecer las opciones de exportar en Excel o PDF.
- **CA-2:** Dado que el archivo sea generado correctamente, entonces el sistema deberá iniciar la descarga automáticamente.
- **CA-3:** Dado que el reporte esté vacío, entonces el sistema deberá mostrar: 'No hay datos disponibles para exportar'.
