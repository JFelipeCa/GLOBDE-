## Historia

**Como** cliente,
**quiero** ver el historial completo de mis citas anteriores con el detalle de cada servicio recibido,
**para** llevar un seguimiento de los tratamientos realizados y consultar información de visitas pasadas cuando lo necesite.

---

## Criterios de aceptación

- **CA-1:** Dado que el cliente accede a su historial, entonces el sistema deberá mostrar todas las citas pasadas con fecha, servicio, barbero y estado.
- **CA-2:** Dado que el cliente seleccione una cita del historial, entonces el sistema deberá mostrar el detalle completo incluyendo el costo.
- **CA-3:** Dado que no existan citas anteriores, entonces el sistema deberá mostrar el mensaje: 'Aún no tienes citas registradas'.
