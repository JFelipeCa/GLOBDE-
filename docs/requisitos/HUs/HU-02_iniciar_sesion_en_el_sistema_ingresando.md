## Historia

**Como** usuario,
**quiero** iniciar sesión en el sistema ingresando mi correo electrónico y contraseña previamente registrados,
**para** poder acceder de forma segura a las funcionalidades del sistema y gestionar la información correspondiente a la barbería.

---

## Criterios de aceptación

- **CA-1:** Dado que el usuario ingresa sus credenciales correctamente, entonces el sistema le permitirá acceder y mostrará las opciones según su rol.
- **CA-2:** Dado que las credenciales son incorrectas, entonces el sistema deberá mostrar un mensaje de error en el inicio de sesión.
- **CA-3:** Dado que el usuario no esté registrado, entonces el sistema deberá mostrar un mensaje indicando que el correo no existe.
