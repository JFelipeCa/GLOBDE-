## Historia

**Como** administrador,
**quiero** ver un reporte de ingresos del negocio filtrado por período de tiempo (día, semana o mes),
**para** analizar el desempeño económico de la barbería y tomar decisiones informadas sobre la operación del negocio.

---

## Criterios de aceptación

- **CA-1:** Dado que el administrador selecciona un período, entonces el sistema deberá mostrar el total de citas, servicios realizados y monto facturado.
- **CA-2:** Dado que no haya datos en el período seleccionado, entonces el sistema deberá indicarlo con un mensaje informativo.
- **CA-3:** Dado que el administrador cambie el período, entonces el sistema deberá actualizar el reporte automáticamente.
